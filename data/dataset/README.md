# IBM HR Analytics Employee Attrition Dataset

Silakan unduh dataset resmi IBM HR Analytics dari Kaggle:
- **Link Kaggle:** [IBM HR Analytics Attrition Dataset](https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset)
- Simpan file CSV dengan nama `WA_Fn-UseC_-HR-Employee-Attrition.csv` di direktori ini (`data/dataset/`).

## Keterangan Kolom Utama:
- `Attrition`: Target variable (Yes / No)
- `Age`, `Department`, `JobRole`, `MonthlyIncome`, `OverTime`, `YearsAtCompany`, dll.
